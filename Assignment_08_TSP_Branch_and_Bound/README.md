# Assignment 8 - TSP using Least Cost Branch and Bound

Files:
- `TSP.cpp` — C++ implementation.
- `Sample_Input.txt` — sample cost matrix.
- `Output.txt` — output from the sample run.

Compile with g++:
`g++ -O2 -std=c++17 TSP.cpp -o TSP`

Run:
`./TSP` on Linux/Ubuntu, or `TSP.exe` on Windows after compiling.

Enter the number of cities, followed by the cost matrix. Use `-1` for a missing direct route. The program finds a minimum-cost tour starting and ending at City 1.
